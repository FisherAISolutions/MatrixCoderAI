# Matrix Coder AI Private Beta

1. Sign in with the invited email address.
2. Create or open a Project. A Project owns its plan, files, messages, engineering state, and deployment metadata.
3. Describe the idea naturally in Matrix AI Architect. Accept or reject recommendations and correct earlier answers.
4. Approve the Architect plan only when the summary matches the intended product.
5. Review and approve the Blueprint.
6. Start Guided Build. Matrix executes bounded tasks, validates each task, and preserves completed work.
7. Use **Stop**, **Pause**, **Resume**, or task-level **Retry** when needed. Advanced IDE exposes files, logs, terminal, and preview.
8. Review the evidence-based completion summary. Blocked environment work is not counted as passed.
9. Add required environment variables through the target hosting provider. Never paste secrets into chat or project files.
10. Use Deployment Center for production checks, ZIP export, and guarded staging deployment.

Usage limits and current plan state appear in billing surfaces. Reaching a limit must not remove access to existing projects or exports.

To report a problem, include the project name, approximate time, operation ID, current milestone, and visible error. Never send passwords or provider tokens.
